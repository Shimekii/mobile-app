# 🌬️ AirCheck

**AirCheck** — мобильное приложение, которое позволяет пользователю отслеживать качество воздуха в текущем местоположении с помощью GPS смартфона. При запуске приложения и разрешении доступа к геолокации, либо выборе города вручную оно собирает данные через Open-Meteo API, отображая параметры загрязнения воздуха, включая PM2.5, PM10 и другие показатели. Пользователь может видеть текущие значения метрик, прогноз качества воздуха на ближайшее время и выбрать несколько городов для отслеживания. Решение помогает принимать повседневные решения о проветривании, прогулках или активностях на улице.

## 🚀 Как запустить приложение

Инструкция рассчитана на любого пользователя:

1. Установите [Flutter SDK](https://docs.flutter.dev/get-started/install) и [Android Studio](https://developer.android.com/studio) или [VS Code](https://code.visualstudio.com/) с плагинами Flutter и Dart.  
2. Скачайте или клонируйте репозиторий:
   `git clone <URL_репозитория>`
   `cd AirCheck`
3. Установите зависимости:
   `flutter pub get`
4. Подключите устройство или запустите эмулятор (Android).
5. Запустите приложение:
   `flutter run`
6. Входная точка — main.dart. При первом запуске приложение запросит доступ к геолокации.

## 🎯 Реализованный сценарий
**Выбор основного города**

Пользователь открывает приложение впервые

Система предлагает определить город автоматически по GPS или выбрать вручную

При разрешении доступа к геолокации приложение получает координаты и отображает качество воздуха

Альтернативный поток: если пользователь запрещает доступ к GPS, система показывает сообщение и предлагает выбрать город вручную.

## ✨ Ключевые фичи

Добавление основного города — выбор города вручную или получение через GPS

Постоянное информирование — уведомления о загрязнении с выбором периода (30/45/60 минут)

Список отслеживаемых городов — добавление нескольких городов и просмотр их качества воздуха

Прогноз на несколько дней — автоматический ежедневный прогноз для основного города
